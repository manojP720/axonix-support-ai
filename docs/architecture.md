
# Axonix Support AI

## Project Overview
An AI-powered customer support automation platform.

## Technology Stack
- n8n: Workflow orchestration
- Ollama: Local AI inference
- Llama 3.2 3B: Language model
- React: Frontend
- FastAPI: Backend
- PostgreSQL: Database

## Core Features
1. AI Customer Chat
2. FAQ Knowledge Base
3. Conversation Memory
4. Order Tracking
5. Support Ticket Creation
6. Human Escalation
7. Admin Dashboard

## Initial Architecture
Customer → React → n8n → AI Agent → Ollama

## Development Approach
Build incrementally, test every component,
and document all integrations.
